# Luna ☾ — حاجة حلوة ليكي

حكاية تفاعلية بالعربي المصري، مبنية بـ React وVite وCSS، من غير تسجيل أو قاعدة بيانات أو تتبّع.

## تعديل الرسائل والصور

كل المحتوى في **`src/content.ts`**، في أول ملف:

- `specialDate`: اليوم والشهر؛ القيم الحالية 1 و7. السنة تُتجاهل تلقائيًا.
- `firstMessage`: رسالة القلب الأولى.
- `photos`: قائمة الصور، ومسار كل صورة، ونصها البديل، وتعليقها الاختياري.
- `happyMessage`: الرسالة الأخيرة.
- باقي الكائنات: العناوين والرسائل وأزرار التنقل والـ footer.

### إضافة الصور

1. ضيفي صورك داخل `public/images/`؛ مثلًا `photo-1.jpg`.
2. في `photos` داخل `src/content.ts`، غيّري `src` من `""` إلى `"/images/photo-1.jpg"`.
3. غيّري `alt` لو حبيتي، وأضيفي `caption` أو سيبيه `""` لو من غير تعليق.

المسارات والأسماء الموجودة في الكود مجرد أمثلة، وليست صورًا لأشخاص. قبل إضافة الصور بتظهر 4 بطاقات أنيقة جاهزة، من غير أي طلب صورة مكسور. تقدر تزودي لحد 6 صور.

## التشغيل

- `npm install`
- `npm run dev`
- `npm run build` لإنشاء نسخة الإنتاج في `dist/`.

## الاختبارات

- `node --test tests/date.test.mjs` لاختبار صيغ التاريخ والأرقام العربية ورسائل الخطأ في الإعدادات.
- `npx playwright install chromium` ثم `node --test tests/browser.test.mjs` لاختبار التفاعل. اختبارات المتصفح تحتاج تشغيل `npm run dev -- --host 0.0.0.0` على المنفذ 5173 أولًا.

اختبارات المتصفح تغطي الرحلة على 360px، والصيغ المختلفة، والمحاولات غير المحدودة، والرجوع للبداية، والصور الفارضة، وتكبير الصور، وEscape، ونافذة الصور، وعدم وجود تمرير أفقي على مقاسات مختلفة، واحترام تقليل الحركة.

## الخصوصية وإمكانية الوصول

- كل الأصول والخطوط محلية؛ مفيش تحليلات أو إرسال بيانات.
- مفيش موسيقى تلقائية أو طلب صلاحيات.
- التحقق والرسائل داخل الصفحة، ورسائل الخطأ متاحة لقارئ الشاشة.
- الأزرار مناسبة للمس، والنوافذ فيها إغلاق واضح وحبس للتركيز، وEscape للإغلاق.
- `prefers-reduced-motion` بيوقف الحركة الزخرفية والقصاصات.

الرسمة الأصلية للهلال والقلب مرفقة بصيغة WebP المضغوطة، والخطوط Cairo وCormorant Garamond محلية مع تراخيصها داخل `public/fonts/`.
